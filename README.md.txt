## What I Learned

### Compile Errors

- **CS1002 – ; expected:** This error occurs when a statement is missing its required semicolon. I triggered this error by removing the semicolon at the end of the first Console.WriteLine statement.

- **CS0103 – The name 'console' does not exist in the current context:** This error occurs when the compiler cannot recognize a name. I triggered this error by changing Console to lowercase console. This showed me that C# is case-sensitive.

### Integer Division Prediction

My prediction for 250 / 4 using int values was 62 because integer division removes the decimal portion of the result. The actual result was 62, with a remainder of 2. When I converted the total bill into a double, the exact share became PHP 62.50.
